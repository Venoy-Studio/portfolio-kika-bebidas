## 🌟 Sobre o Projeto

A **Kika Bebidas** é uma distribuidora e rede de bebidas com experiência de compra digital moderna: vitrine de produtos categorizados (cervejas, destilados, vinhos, gelo e carvão), carrinho interativo e localização por geolocalização.

## ✨ Principais Destaques

- **Catálogo Dinâmico**: Organização por marcas, volumes e tipos de bebida.
- **Seletor de Unidades & Lojas Próximas**: Identifica a unidade mais próxima para entrega rápida.
- **Drawer de Carrinho de Compras**: Gestão de pedidos fluida sem recarregar a página.

## 🚀 Como Executar Localmente

```bash
git clone https://github.com/Venoy-Studio/portfolio-kika-bebidas.git
cd portfolio-kika-bebidas
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).
